# HR-ассистент (Telegram-бот)

Telegram-бот для новичков компании: отвечает на вопросы о графике работы, отпусках, корпоративных правилах, контактах отделов, анализирует присланные картинки. Поддерживает текст, голосовые сообщения и режим RAG по базе знаний.

## Требования

- Python 3.11+
- Файл **.env** в корне проекта с переменными:
  - `OPENAI_API_KEY` — ключ OpenAI
  - `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)

## Установка и запуск

```bash
cd C:\Users\Пользователь\PEm09
python -m pip install -r requirements.txt
python main.py
```

При первом запуске скачивается модель эмбеддингов для RAG (sentence-transformers); дождитесь завершения загрузки.

## Команды бота

| Команда | Описание |
|--------|----------|
| `/start` | Приветствие и подсказки |
| `/help` | Справка по командам |
| `/reset` | Очистить историю диалога |
| `/stats` | Статус базы знаний (кол-во документов, путь) |
| `/mode rag` | Включить ответы по базе знаний с указанием источника |
| `/mode text` | Обычный режим без RAG |
| `/mode voice` | Голосовой режим: голос → расшифровка → ответ (текст + голос) |

## База знаний

Текстовые файлы (`.txt`) в папке **data/** автоматически индексируются при старте и используются в режиме RAG. Добавляйте туда справочники, регламенты, контакты.

## Структура проекта

- **handlers/** — обработчики Telegram: команды, текст, голос, картинки
- **services/** — роутер запросов, память диалога, клиент OpenAI (LLM, Vision, STT, TTS)
- **rag/** — индексация и поиск по базе знаний (ChromaDB)
- **utils/** — конфиг и пути (загрузка из `.env`)
- **data/** — база знаний (справочники в формате .txt)
